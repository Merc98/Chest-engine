# Custom Types

This folder is reserved for documenting custom value types and verified examples.

## Purpose

Custom types can be documented here when their implementation and behavior are confirmed from the source tree.

## Suggested layout

```text
custom-types/
  README.md
  templates/
    custom-type-notes.md
```

## Documentation checklist

For each custom type, document:

- name;
- purpose;
- value format;
- source file;
- scan behavior;
- display behavior;
- example input/output;
- limitations observed in code.
