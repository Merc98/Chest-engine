# Lua Subsystem Overview

Chest-engine includes a large Lua integration layer. The project entry point references many `Lua*` units, which indicates that Lua is used across automation, UI scripting, memory scanning, tables and trainer logic.

## Areas covered

The Lua subsystem appears to cover:

- script execution;
- scan automation;
- found-list handling;
- memory record handling;
- form and UI scripting;
- timer/event scripting;
- pipe and network interaction;
- disassembler helpers;
- structure interaction;
- table-file automation;
- component wrappers.
