# Workspaces

This folder documents a suggested layout for organizing analysis sessions and project notes.

## Suggested layout

```text
workspaces/
  example-workspace/
    scans/
    tables/
    scripts/
    symbols/
    snapshots/
    notes/
```

## Purpose

A workspace can group files related to one analysis session or project:

- scan notes;
- table files;
- Lua scripts;
- symbol notes;
- snapshots;
- report drafts.

## Template

Use `workspaces/example-workspace/README.md` as a starting point.
